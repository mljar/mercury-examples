# Mercury Examples

Example Jupyter notebooks showing how to turn data analyses into web apps with
the [Mercury framework](https://runmercury.com/).

## Examples

- [Tech layoffs activity calendar](layoffs/) — filter Layoffs.fyi data and
  visualize daily reported layoffs or event counts.
- [GitHub incidents activity calendar](github-outages/)
- [Who Is Hiring analyses](who-is-hiring/) — two apps based on monthly Ask HN
  hiring threads:
  - [Remote Tech Job Funnel](who-is-hiring/who-is-hiring-funnel.ipynb) narrows
    entries by year, work arrangement, language, role family, and compensation.
  - [Programming Language Sankey](who-is-hiring/language-mentions-sankey.ipynb)
    compares language mentions across selected years.
- [Pivot table](pivot-table/)
- [PyDeck](pydeck/)
